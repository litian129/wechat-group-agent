# 企业微信群聊智能体 - 项目规格说明

## 1. 项目概述

### 1.1 项目名称

企业微信群聊智能体 (WeCom Group Chat Agent)

### 1.2 业务背景

清新全家科迈斯诺是一家提供室内除甲醛治理服务的公司。服务流程涉及多个角色（销售、师傅、工程部负责人）在微信群中协同服务客户。需要智能体自动监听群聊消息，识别客户/销售意图，在适当时机触发自动回复，提升服务响应效率。

### 1.3 核心目标

- 自动识别销售发送的订单信息，自动发送服务前摇文案并@师傅
- 自动识别客户各类咨询（预约时间、合同、施工、药剂），在无人响应时自动@对应角色并安抚客户
- 减少客户等待焦虑，提升群内服务响应速度

## 2. 输入/输出规格

### 2.1 输入格式 (JSON)

```json
{
  "group_name": "群名称",
  "messages": [
    {
      "userid": "用户显示名称",
      "role": "销售|师傅|工程部负责人|内部其他人|客户",
      "content": "消息内容",
      "timestamp": "2026-08-18T10:00:00",
      "msgid": "唯一消息ID",
      "is_last_in_window": true
    }
  ]
}
```

### 2.2 输出格式 (JSON)

```json
{
  "group_name": "群名称",
  "triggered": true,
  "trigger_type": "booking|appointment_timeout|contract_timeout|construction_timeout|medication_timeout",
  "responses": [
    {
      "at_target": ["@师傅"] | ["@销售"] | ["@销售", "@工程部负责人"],
      "content": "回复内容"
    }
  ]
}
```

### 2.3 当无触发时输出

```json
{
  "group_name": "群名称",
  "triggered": false,
  "trigger_type": null,
  "responses": []
}
```

## 3. 触发条件规格 (核心业务逻辑)

### 触发1: 销售发送订单信息 (booking)

- **触发条件**: 消息发送者角色 = "销售"，消息为包含冒号的结构化长文本
- **识别特征**: 消息含多个"关键词：值"对（上门时间、标准、平台、面积、姓名、电话、地址等）
- **行动**:
  1. 解析订单信息（提取姓名、电话、地址、上门时间等）
  2. 从本地 master_info.json 查找对应师傅信息
  3. 发送两大段前摇文案
  4. @师傅 + "请主动联系客户确认上门时间~"
- **前摇文案** (固定模板，见 config/response_templates.yaml)

### 触发2: 客户咨询预约时间 + 超时无响应 (appointment_timeout)

- **触发条件**: 消息发送者角色 = "客户"，消息内容涉及预约时间，且3~7分钟内无人响应
- **意图关键词**: 预约、时间、明天、上午、下午、几点、改时间、可以吗、方便、之后
- **行动**: @师傅 + 安抚文案
- **响应模板**: "师傅可能正在工作，我们已经提醒师傅尽快联系您~"

### 触发3: 客户咨询合同 + 超时无响应 (contract_timeout)

- **触发条件**: 消息发送者角色 = "客户"，消息内容涉及合同/协议/个人信息，且3~7分钟内无人响应
- **意图关键词**: 合同、签、协议、个人信息、纸质、填表、条款
- **行动**: @销售 + 合同说明 + 安抚文案
- **响应模板**: "{合同相关一般性说明}，我们已经联系销售尽快联系您~"

### 触发4: 客户咨询施工 + 超时无响应 (construction_timeout)

- **触发条件**: 消息发送者角色 = "客户"，消息内容涉及现场施工，且3~7分钟内无人响应
- **意图关键词**: 施工、进人、屋子、呆、影响、现场、治理、人不在、能不能
- **行动**: @销售 + 安抚文案
- **响应模板**: "师傅可能正在工作，我们已经提醒师傅尽快联系您~"

### 触发5: 客户咨询药剂 + 超时无响应 (medication_timeout)

- **触发条件**: 消息发送者角色 = "客户"，消息内容涉及药剂/甲醛/气味，且3~7分钟内无人响应
- **意图关键词**: 药剂、甲醛、味道、催化、释放、气味、无色无味、 chemicals、安全
- **行动**: @销售 + @工程部负责人 + 安抚文案
- **响应模板**: "这两位是我们专家，会尽快解决您的担忧~"

## 4. 角色定义

| 角色标识     | 显示名称   | 职责          |
| -------- | ------ | ----------- |
| sales    | 销售     | 接单、合同沟通     |
| master   | 师傅     | 上门治理、检测服务   |
| eng_head | 工程部负责人 | 施工质量、药剂专业问题 |
| internal | 内部其他人  | 其他内部人员      |
| customer | 客户     | 服务接收方       |

## 5. 技术约束

- 输入为 JSON 文件，需支持批量消息处理
- 意图分类采用"关键词规则引擎 + 加权评分"混合方案，无需外部API
- 响应模板支持变量插值（师傅姓名、电话等）
- master_info.json 为本地配置文件，存储师傅信息
- 超时判断：JSON 输入已标注消息是否在3-7分钟窗口内且无人响应
