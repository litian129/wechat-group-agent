## 2. 模块职责

| 模块 | 职责 | 输入 | 输出 |
|------|------|------|------|
| MessageParser | 解析JSON会话窗口 | 原始JSON | List[Message] |
| RoleManager | 用户角色映射 | userid | Role |
| IntentClassifier | 意图分类 | 消息文本 | IntentType+score |
| TriggerEngine | 触发条件评估 | Message+Intent | TriggerType |
| BookingHandler | 处理触发1(订单) | 消息+师傅信息 | Response |
| TimeoutHandler | 处理触发2-5(超时) | 消息+意图 | Response |
| ResponseGenerator | 生成最终回复 | 模板+变量 | 文本内容 |

## 3. 技术选型

- **语言**: Python 3.12+
- **依赖**: 仅标准库 (json, re, dataclasses, typing)
- **意图分类**: 关键词规则引擎 + 加权评分（无需外部API/LLM）
- **配置**: JSON 格式（零外部依赖）
- **测试**: unittest 标准库

## 4. 核心算法

### 4.1 订单信息识别 (触发1)
```python
# 规则: 消息中 "key：value" 或 "key:value" 模式出现 >=3次
pattern = r'[\u4e00-\u9fa5]{2,8}[：:][^\s]+'
matches = re.findall(pattern, content)
if len(matches) >= 3 and role == "销售":
    trigger = "booking"
```

### 4.2 意图分类 (触发2-5)
```python
# 每个意图类别配置加权关键词
intent_keywords = {
    "appointment": {"预约":3, "时间":2, "明天":2, "上午":2, "下午":2, ...},
    "contract": {"合同":3, "签":2, "协议":3, "个人信息":3, ...},
    "construction": {"施工":3, "进人":2, "屋子":1, "治理":2, ...},
    "medication": {"药剂":3, "甲醛":3, "味道":2, "催化":2, "释放":2, ...}
}
# 计算各类别得分，取最高分超过阈值者
```

### 4.3 超时判断
```python
# JSON 输入已标注: is_last_in_window=True 表示该消息在3-7分钟窗口内
# 且 has_response_after=False 表示无人响应
if msg.is_last_in_window and not msg.has_response_after:
    trigger = intent_type + "_timeout"
```

## 5. 数据流

```
输入JSON → 解析消息列表 → 遍历每条消息
  → 识别发送者角色
  → 分类消息意图
  → 评估触发条件
    → 触发1: 解析订单 → 查找师傅 → 生成前摇+@师傅
    → 触发2-5: 判断超时 → @对应角色 → 生成安抚文案
  → 汇总所有响应
  → 输出JSON
```
